# Dr. Nishita Ranka - Skin Boosters & IV Drips Landing Page

A standalone, performance-marketing landing page for dermatologist-led Skin
Booster treatments (SKINVIVE™, RD1, Profhilo®) paired with a complimentary
doctor-led IV wellness benefit, at Dr. Nishita's Clinic in Banjara Hills,
Hyderabad.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm run lint
npm test
```

## Page structure

The page follows the clinic's dark-pink editorial visual system shared
across Dr. Nishita's other treatment landing pages: a proof-led hero with a
low-friction consultation form, dermatologist authority section, the three
Skin Booster protocols with a side-by-side comparison table, the treatment
journey, skin concerns addressed, patient voices, the complimentary IV
wellness benefit, FAQs, and clinic information with the full terms and
medical disclaimer.
